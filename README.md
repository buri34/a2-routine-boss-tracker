# A2 ルーティン&ボストラッカー v0.2.37

AION2 Global Japan向けの日課・週課・ワールドボス管理ツールです。Tauri 2で作られたWindows 11用アプリで、外部サーバーやログインを使いません。

> [!IMPORTANT]
> 本ソフトウェアは非公式のコミュニティツールです。AION2およびNCSOFTの開発・運営元とは関係ありません。

## 利用者向け

GitHub Releasesから、次のいずれかを取得します。

- **インストーラー（推奨）**: WebView2 Runtimeがない環境では、Microsoftの公式ブートストラッパーを使って導入します。この場合はインターネット接続が必要です。
- **ポータブルZIP**: 任意のローカルフォルダーへ展開し、`A2RoutineBossTracker.exe`を起動します。WebView2 Runtimeが別途必要です。

配布物はReleaseの`SHA256SUMS.txt`と照合できます。現在の配布物はコード署名されていないため、Windows SmartScreenが表示される場合があります。配布元とSHA-256を確認してから実行してください。

旧AION2 Helperから更新する場合は、先にタスクトレイの旧版を右クリックし、**「完全に終了」**を選んでください。旧版が動いたまま新版EXEを起動すると、単一起動機能により旧版の画面が再表示されます。起動中の名称と版は左上とウィンドウタイトルで確認できます。保存先識別子は維持しているため、旧版のキャラクター名・進捗・設定を引き継ぎます。

- 画面右上の閉じるボタンでは終了せず、タスクトレイへ格納されます。
- 完全終了は、トレイアイコンを右クリックして「完全に終了」を選びます。
- データはWindowsのユーザーデータ領域へ保存され、EXEを差し替えても維持されます。
- JSONバックアップは「設定・データ」画面からダウンロードフォルダーへ出力できます。

## 実装済み

- 1〜8キャラクター（既定4枠）
- キャラクター別の自由記述メモと選択文字用カラーパレット
  - 本文の一部を選択し、8色から個別に着色
  - 外部からの貼り付けは文字と改行だけを取り込み
- アカウント共有／キャラクター個別の日課・週課
- 各項目の★で、ダッシュボードの管理対象を共有項目・キャラクターごとに個別設定
  - 初期状態ではキャラクター1を全項目の管理対象とし、キャラクター2以降は一部の日課・週課を管理対象外に設定
  - 対象外にしても入力値は保持し、再び★を付けるとそのまま復帰
  - 悪夢・自然回復オード・アビス回廊もキャラクターごとに★／☆を選択可能
  - ☆の状態項目は警告・サマリー・優先順位候補・回廊期限通知から除外
- 「次にやること」に優先度順の上位5件を表示
  - 最優先／高／通常／低を、共有タスクとキャラクター別タスクに設定
  - オード720未満／以上、悪夢10未満／以上、回廊権利ありにもキャラクターごとに設定
  - ★を外したタスク・状態は優先順位設定と候補一覧の両方から除外
  - 優先順位設定はダッシュボードを押し下げず、専用モーダルで表示
  - 初回起動時は項目の性質に合わせた推奨優先度を設定済み（利用者が自由に変更可能）
- 全体サマリーから未完了項目を展開し、対象の共有・キャラクター画面へ直接移動
- キャラクター横断一覧で警告の原因を項目名・残数付きで表示
- 自然回復オードが720以上になったキャラクターを早期警告
- 悪夢の保有数が10以上になったキャラクターを早期警告
- JST固定のデイリー・ウィークリー更新
- シューゴ、次元侵攻、悪夢、オードの定時回復
- 全数値カウンターの直接入力と±調整
- ウィークリー任務を魔族大陸12件・アビス20件で個別管理（合計32件）
- 魔族/天族・アビス別のワールドボス周期管理
- ガルトゥア／ラグタ／精霊王アグロ（12時間）、タルタン／カシャパ（6時間）、監視者カイラ（3時間）の次回出現計算
- 守護神将ナフマ（金曜・日曜21:00）の週次出現計算
- ボスごとのWindows通知（複数タイミング選択、重複防止）
  - 初期状態はガルトゥア／ラグタが30・10・5分前、タルタン／カシャパが10・5分前
- シューゴフェスタ（毎時00分）・次元侵攻（毎時30分）・時空の裂け目（17:00基準の3時間周期）の定期イベント通知
  - イベントごとに10／5／3／1分前を個別選択
- 周期ボスの基準時刻と、曜日指定ボスの出現時刻を編集可能
- 40／80固定単位消費（自然回復分を優先）
- アビス回廊権利の一括付与・個別消化・AF戦時失効
- Windows通知、タスクトレイ、単一起動
- JSONバックアップ／復元

## 開発・ビルド

必要環境：Node.js LTS、Rust stable MSVC、Visual Studio 2022 C++ Build Tools、WebView2。

```powershell
npm ci
npm test
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri -- build --no-bundle
```

ポータブルEXEは`src-tauri/target/release/A2RoutineBossTracker.exe`へ生成されます。

NSISインストーラーを生成する場合は、次を実行します。

```powershell
npm run tauri -- build --bundles nsis
```

インストーラーは`src-tauri/target/release/bundle/nsis/`へ生成されます。インストーラーはWebView2 Runtimeの有無を確認し、必要な場合だけMicrosoftの公式ブートストラッパーを実行する設定です。
